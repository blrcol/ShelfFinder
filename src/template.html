    Connections & setup

    Live Colgate catalog

    Paste the web-app URL of the ShelfFinder catalog proxy (the Google Apps Script that holds the API key — see server/SETUP.md). The API key itself never goes in the app.

    Shared database

    Connect a Firebase Realtime Database so every phone sees the same locations live. Leave empty to work locally.

    Catalog data

    CSV needs “Title” and “Call Number” columns (Author, ISBN/Barcode, Status optional) — the format most catalog exports use.

    Markers & calibration

    Tape them at each stair landing, elevator, entrance and on the end of each cataloged range.

    About ShelfFinder

    ShelfFinder is a student project built for Case-Geyer Library. It is not an official Colgate University service. For help finding anything, ask at the Circulation Desk on Level 3.

    Location data is updated by library staff and may not reflect every recent move.
